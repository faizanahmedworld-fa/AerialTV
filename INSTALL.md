# Installing Aerial TV

This guide is for the person setting up the TV, not for developers. It takes about 5 minutes and you only do it once.

You need the APK file, `Aerial TV 1.0.apk`, or a link to it: [your download link].

## Android TV or Google TV box (Mi Box, Chromecast with Google TV, TCL, Sony, cheap TV boxes)

1. On the TV, open the Google Play Store and install **Downloader** by AFTVnews. It's free.
2. Open **Settings → Device Preferences → Security & restrictions → Unknown sources** and switch on **Downloader**. On Google TV it's **Settings → System → About**, click **Android TV OS build** 7 times, then **Settings → Apps → Security & restrictions → Unknown sources → Downloader**.
3. Open Downloader, type the download link with the remote and press **Go**.
4. When the download finishes, press **Install**, then **Open**.
5. Pick your country. Your country is normally already at the top, so just press **OK**.

Aerial TV now sits on the TV's home screen with its own tile.

## Amazon Fire TV Stick

1. On the Fire TV home screen, search for **Downloader** and install it.
2. Go to **Settings → My Fire TV**. If you don't see **Developer options**, open **About**, click the device name 7 times, then go back.
3. Open **Developer options → Install unknown apps** and switch on **Downloader**.
4. Open Downloader, type the download link and press **Go**, then **Install** and **Open**.
5. Pick your country and press **OK**.

To put it on the home row: hold the Home button, choose **Apps**, find Aerial TV, press the menu button (three lines) and pick **Move to front**.

## From a USB stick

1. Copy `Aerial TV 1.0.apk` onto a USB stick from a computer.
2. Plug it into the TV box.
3. Install a file manager from the Play Store (X-plore File Manager and File Commander both work), open the USB stick and click the APK.
4. If the TV asks, allow the file manager to install apps, then press **Install**.

## Android phone or tablet

1. Open the download link in Chrome.
2. Tap the downloaded file. If Android asks, tap **Settings** and allow Chrome to install apps, then go back.
3. Tap **Install**, then **Open**.

On a phone, tap the screen for the channel list and swipe up or down to change channel.

## Using it

| Remote button | What it does |
| --- | --- |
| ▲ or CH+ | Next channel |
| ▼ or CH− | Previous channel |
| OK or ◀ | Channel list |
| ▶ | Shows what's on now |
| Number keys | Go to that channel number |
| Hold OK on a channel in the list | Add it to Favourites |
| Back twice | Close Aerial TV |

The country button at the top of the channel list changes country.

## When something goes wrong

**"Channel is off air right now"**: that free stream isn't working today. Aerial TV moves to the next channel by itself. Nothing to fix.

**"Can't reach the internet"**: check the WiFi or cable on the TV box, then press **Try again**.

**A channel freezes**: wait about 20 seconds. Aerial TV tries the channel's backup link, then moves on.

**Wrong country or a mess of settings**: go to **Settings → Apps → Aerial TV → Clear data**. Next time it opens, it asks for the country again.

**Some channels only work in their own country.** A Pakistani channel might play in Lahore and not in Dubai. That's the broadcaster's choice, not the app.

## Updating

Install the new APK the same way, over the top of the old one. Favourites and the last channel are kept.
